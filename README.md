# Sabina Vantuchová
LegGen Soy 5K trait-specific marker panel interpretation tool
Python skript pro automatické zpracování genotypizačních dat ze sóji luštinaté (Glycine max). Nástroj vyhodnotí genotypizační data vzorků, předpoví jejich výsledný fenotyp a vygeneruje přehlednou barevnou vizualizaci matic.

Vstupní soubory jsou umístěny ve složce IMPORT.
Výsledný soubor je uložen do složky phenotype_evaluation.
